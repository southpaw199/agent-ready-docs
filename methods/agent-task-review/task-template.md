# Task template

Copy this block into a case study's `tasks.md` once per task.

```markdown
## Task <id>: <short name>

**Prompt given to the agent:**
> <The exact words you give the agent, written the way a developer would ask.>

**Docs area exercised:** <for example: quickstart, embeddings, indexing>

**Success criteria:**
- <A result you can check by running the code, for example: "returns the top 3 rows with an id column">
- <...>

**Starting state:** <empty folder and fresh virtual environment, plus anything provided, such as a sample data file>

**Out of scope:** <anything the agent should not need, for example: a cloud account or API key>
```
